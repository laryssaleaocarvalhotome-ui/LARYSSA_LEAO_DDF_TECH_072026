# Plataforma de Dados para E-commerce

## Processo Seletivo – Dadosfera

**Candidata:** Laryssa Leão de Carvalho Tomé

## Objetivo

Este projeto foi desenvolvido como parte do processo seletivo para a vaga de Administrative | Operations Intern da Dadosfera.

O objetivo é demonstrar o ciclo completo de um projeto de dados, contemplando integração, tratamento, qualidade, modelagem, análise e visualização dos dados de um ambiente de e-commerce.

## Estrutura do Projeto

- Planejamento
- Base de Dados
- ETL
- Qualidade dos Dados
- IA Generativa
- Modelagem Dimensional
- Dashboard
- Data App
- Documentação

## Tecnologias

- Python
- SQL
- GitHub
- Dadosfera
- Streamlit
- Power BI
